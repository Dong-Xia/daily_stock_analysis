# 选股模块设计思想

## 核心理念：自上而下的战场地图

选股不是"翻石头"，而是**读地图 → 选战区 → 找据点**。

```
宏观 → 板块 → 个股 → 仓位 → 风控 → 执行
  ①      ②      ③      ④      ⑤      ⑥
```

每一层都卡住下一层的输入。后面再精密的计算，如果方向是错的，全是白费。

---

## ① 市场阶段分类 — "今天该不该打"

### 问题
绝大多数亏损不是因为选错了股，而是**在错误的时间做了错误的决策**。牛市什么策略都好用，熊市什么策略都容易亏。

### 方案：Quant + LLM 双层

```
Quant 层（纯计算）→ 7 种量化阶段 + 置信度
LLM 层（可选）   → 宏观归因、风险提示
```

**为什么 ML？不是 ML，是规则引擎。** ML 需要大量标注数据，且解释性差。规则引擎基于 MA 排列、量能比、涨跌家数等经典技术指标，输出确定的阶段标签和仓位系数。金融领域，可解释性 > 黑盒精度。

**7 阶段 vs 传统的 3 阶段（牛/震/熊）**：更细的颗粒度能在过渡期给出更精确的仓位指导。例如"底部反转"阶段允许 50% 仓位试探，而"主跌趋势"建议 10% 以下。

### 关键设计选择

| 维度 | 指标 | 权重 | 选择理由 |
|------|------|------|----------|
| 趋势 | MA5/10/20/60 排列 | 35% | 技术分析最基础、最稳定的信号 |
| 量能 | 5日/20日均量比 | 20% | 量是价的先行指标 |
| 宽度 | 涨跌家数比 | 20% | 确认趋势的广度（避免指数失真） |
| 波动 | ATR 比值 | 10% | 高波动→减仓，低波动→蓄势 |
| 情绪 | 涨停/跌停家数 | 15% | A股特有的情绪指标 |

**为什么趋势权重最高（35%）？** A 股在统计上是强趋势市场（动量效应显著），趋势一旦形成，持续性远高于美股。

## ② 板块锁定 — "水流向哪里，鱼就在哪里"

### 问题
A 股是板块轮动驱动的市场。每天有几十个板块涨跌，大部分是一日游。**能把"主线"和"脉冲"区分开的人，就已经赢了 90% 的选股者。**

### 方案：多日持续性 + 三维分类

```
核心识别维度:
  持续性(consecutive)：连续几天出现在排行榜前 N
  频率(appearance)：过去 N 个交易日出现比例
  趋势(score_trend)：评分的时间序列斜率

分类输出:
  🔥 主线      — 连续≥5天 + 频率≥60%     → 重点参与
  🚀 强势轮动  — 连续≥3天 + 频率≥40%     → 观察确认
  🔄 轮动      — 频率≥30%                 → 正常参与
  ⚡ 脉冲      — ≤2天 + 低频              → 不追
  🆕 异动      — 刚出现 + 趋势向上        → 标记观察
  📉 退潮      — 趋势显著为负             → 回避
```

**为什么不用简单的"涨跌幅排序"？** 前一日涨得最好的板块，次日有显著的均值回归倾向。持续性维度是对抗回归的第一道防线。

### 数据来源

| 数据 | 来源 | 说明 |
|------|------|------|
| 板块排行 | BoardScraper / AkShare | 行业板块 + 概念板块 |
| 涨停池 | BoardScraper | 涨停股、封单额、连板天数 |
| 板块成分股 | SectorCacheService | 板块内个股列表 + 涨跌幅 |
| 资金流 | em_hidden_fetcher | 板块主力净流入/流出 |

## ③ 个股筛选 — "漏斗比满仓更重要"

### 问题
一个板块 50~200 只股票，人类的注意力只能同时处理 3~5 个。**选股不是找"所有好股票"，而是从 N 只中快速筛出最值得深度分析的那几只。**

### 方案：四层漏斗

```
板块成分股 (50-200)
    ↓
L1: 流动性筛    ── 成交额 > 阈值, 换手率 > 阈值   (过滤杂音股)
    ↓
L2: 趋势确认    ── MA5 > MA10 > MA20, 价格 > MA20 (过滤下降趋势股)
    ↓
L3: 板块内排名  ── N日涨幅排序, 保留前 30%          (选出领涨股)
    ↓
L4: 综合评分    ── 多因子加权(R越大越高)             (精排)
    ↓
Top 3-5 候选
```

### 六因子评分

| 因子 | 权重 | 意义 | 得分锚点 |
|------|------|------|----------|
| 趋势强度 | 25% | MA 排列质量 | MA5>MA10>MA20=100, 紊乱=0 |
| 相对强度 RS | 25% | 个股 vs 板块 | RS=2.0→100, RS=0.5→30 |
| 量能确认 | 15% | 近期量 vs 长期量 | 比例>1.3→70+, <0.7→30- |
| 乖离率 | 10% | 距离 MA5 的距离 | <3%=优, >8%=危险 |
| 涨停距离 | 10% | 距涨停板的距离 | <5%=风险高(追涨), >20%=安全 |
| 龙头评分 | 15% | 板块内领涨地位 | 龙头=80, 跟风=50 |

**设计原则**：不去预测"明天会不会涨"，而是判断"这只股票比板块内其他股票好在哪里"。RS（相对强度）是最核心的信号——强势的股票倾向于继续强势。

### 为什么用多因子而不是 ML？

1. **可解释性**：交易决策需要知道自己输在哪里。因子分比黑盒 ML 权重更有意义。
2. **样本量不足**：A 股单板块通常 <200 只，不足以训练有意义的 ML 模型。
3. **数据质量**：因子可以容忍部分数据缺失，ML 不行。

## ④ 仓位计算 — "决定胜负的不是买没买，而是买了多少"

### 问题
**90% 的散户亏钱不是因为选错股，而是选对股但仓位太低，选错股但仓位太高。** 职业交易员和散户最大的区别不在选股，在仓位管理。

### 方案：三层约束的 Kelly 公式

```
推荐仓位 = min(
    Kelly公式:  f* = (p × R - q) / R   ← 最优增长
    风控约束:  单笔亏损 ≤ 账户 2%        ← 生存优先
    市场上限:  max_single_position × regime_factor ← 顺势而为
)
```

### 三层约束的意义

| 约束 | 目的 | 防止 |
|------|------|------|
| Kelly | 长期复利最优 | 仓位过小浪费机会 |
| 风控(R=2%) | 连续 50 次全错不破产 | 单笔过大爆仓 |
| 市场阶段 | 牛市重仓, 熊市轻仓 | 逆势操作 |

**为什么用半 Kelly (fraction=0.5)？** 全 Kelly 的波动性极高，半 Kelly 在保持 75% 的增长效率的同时，将回撤降低约 50%。

## ⑤ 止损 — "买入之前就想好怎么输"

### 问题
**散户最常见的死法：不止损 → 深套 → 被迫变成长期股东 → 底部割肉。** 这不是投资，这是赌博。

### 方案：三层止损失

```
入场前确定:
  Layer 1: 硬止损 — ATR/MA/结构低点 → 确定的出场价
  Layer 2: 移动止损 — 价格每上涨 X% → 止损上移 Y%
  Layer 3: 时间止损 — N 交易日后未验证入场逻辑 → 退出

每笔交易前定义:
  R = |入场价 - 止损价| × 股数  (即"这笔单子最多亏多少钱")
  每笔 R ≤ 账户总资金的 2%
  目标盈亏比: R:R ≥ 1:2
```

### 止损锚点的选择

| 锚点 | 适用场景 | 优势 | 劣势 |
|------|----------|------|------|
| ATR × 2 | 趋势交易 | 自适应波动性 | 对横盘不敏感 |
| MA20 | 上升趋势 | 简单明确 | 牛市回调可能被扫 |
| 波段低点 | 结构交易 | 支撑/阻力明确 | 需要手动识别 |

组合使用：入场用 ATR 止损，趋势形成后用 MA20 移动止损。

## ⑥ 调仓 — "去弱留强，不跟股票谈恋爱"

### 问题
**最大亏损永远来自"曾经赚钱最终亏钱"。** 散户的典型错误：赚 5% 跑掉 → 涨到 50% → 后悔 → 高位追回 → 跌 30% → 死扛。

### 方案：RS 排序 + 事件驱动

```
定时(每周):
  按 RS(个股涨幅/板块涨幅) 排列所有持仓
  Top 50% → 持有/加仓
  Bottom 20% → 减仓/清仓

事件驱动(随时):
  止损触发 → 立即清仓
  龙头切换 → 卖跟风, 买新龙头
```

**为什么用 RS 而不是 PnL 来决策去留？** 亏损的股票可能只是正常的回调，但 RS 低的股票说明它相比板块在走弱——这才是卖出信号。

## 设计原则总结

| 原则 | 含义 | 代码中的体现 |
|------|------|-------------|
| **Top-Down** | 宏观→板块→个股 | 步骤①是②的前置条件 |
| **Best-Effort** | 数据拿不到也要能工作 | 所有外部调用都有 try/except 和默认值 |
| **可解释性 > 黑盒** | 每个分数都要能解释 | 多因子评分 + 每个因子有独立得分 |
| **生存优先** | 先不亏再谈赚 | 仓位 2% 风险上限 + 三层止损 |
| **截断亏损, 让利润奔跑** | 卖出差的, 持有好的 | RS 排名 + 去弱留强 |
| **流程可验证** | 每步都有输出 | CLI `--screen`, `--position-size` 等独立可运行 |
