## 背景

现行"今日回踩完成→明日买入"仅要求：战法信号后 5 日内收盘破 SA 上轨，此后某天最低价 ≤ SB 下轨且当日收阳（不要求收盘收复下轨）。实际出现了"跌破下轨后的低位弱修复阳线"也被标为买点的情况（如 2026-09-14 西部证券：收 6.71 < SB 6.72）。本设计引入两条更严格的量能+价位确认规则。

## 术语与数据

- 蓝色梯子 = MRMC 通道：`SA = EMA(high,24)` 上边缘，`SB = EMA(low,23)` 下边缘；日线数据在 `mrmc_cache_3y.pkl`（含 `volume`，3 年全市场）
- `volma5[i]` = 前 5 个交易日均量（不含当日，rolling(5).shift(1)），避免自参照
- 阳线 = `close > open`
- 战法信号 = `DXX | DXDX` 任一为真

## 规则 1：回踩完成（取代旧口径）

前置（与现有一致）：信号日 s 后 ≤5 个交易日内出现破轨日 b：`close[b] > SA[b]`，记 `V0 = vol[b]`。

1. **缩量贴轨回踩日 p**：b 之后任一日满足 `low[p] ≤ SB[p]×1.01` 且 `vol[p] ≤ 0.72×V0`（回放定稿值，原设计 0.6）
2. **双日确认 (d, d+1)**，d ≥ p，两天每日满足：
   - `1.1×volma5 ≤ vol ≤ 2.5×volma5`（温和放量，排除 >2.5× 爆量诱多）
   - 阳线，且 `close > SB`
   - 且两日中至少一天 `low ≤ SB`（贴住下边缘）
3. `d+1 == 今天` → 状态 `今日回踩完成→明日买入`

**失效**：p 后 10 个交易日内未完成双日确认，或期间任意一天 `close < SB×0.97`（深度破轨）→ 流程复位，回落现有"无信号/等待"文案。

**中间态文案**（仅括注变化，前缀不动以保前端配色）：破轨后未到 p → `已突破,回踩未到SB`；p 已现但双日未成 → `回踩中(等待两日温和放量)`。

## 规则 2：二次放量确认（新状态）

同一信号池、同一前置（s 后 ≤5 日破轨 b），且破轨日需放量：`vol[b] ≥ 1.5×volma5[b]`（起量突破）。

1. **缩量回调**：b 后 ≤10 个交易日内某日 c：`vol[c] ≤ 0.6×vol[b]` 且 `close[c] < SA[c]`（回梯内）
   - 失效：期间任意 `close < SB×0.97` → 复位
2. **二次起量 d1**（c 次日起）：`vol ≥ 1.2×volma5`，阳线，`close > 前一日 close`
3. **量能持续 d2 = d1 次日**：`vol[d2] ≥ 0.8×vol[d1]` 且 `close[d2] > low[d1]`
4. `d2 == 今天` → 状态 `二次放量确认→明日买入`

**同日双触发优先级**：规则 1 > 规则 2（规则 1 贴轨条件更苛刻、更稀有）。


**回放报告**（`replay_rules.py` 输出终端表格 + CSV 到 `stockData/replay_YYYYMMDD/`）：
- 每规则：触发次数、次日开盘买入的 1/3/5 日胜率与平均收益、最好/最差样本
- 对照集：旧口径同参数重放（"被淘汰的信号"的胜率），回答"收紧换来多少质量"
- 参数敏感性：核心参数 ±20% 重跑，胜率波动一行表
